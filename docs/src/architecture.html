One Python package, src/gausser/, with one entry point (gausser = gausser.cli:main), a React page for the monitor in web/, and external tools found on PATH. The tables and the graph on this page are generated from the source.

How the code is layered

  • cli.py parses arguments and is the only place that maps a command to step functions (run_step). guide.py builds a command line for it and adds no behaviour.
  • steps.py holds the pipeline steps; capture-specific work lives in keyframes.py, pano.py, qoocam.py, arkit.py, geo.py; training with Msplat in msplat.py, SAM3 in sam.py (the only module that imports torch).
  • scene.py is the bottom layer: folder layout, the lock, step history and logs, run_tool/require_tool, atomic replace. colmap_model.py and ply.py are the only readers and writers of COLMAP models and PLY files.
  • Commands around the pipeline each have one module: view.py (SuperSplat server, shared with orbit), orbit.py, align.py, crop.py, mapping.py (map).
  • monitor.py only reads; it never takes the lock.
  • Heavy imports (numpy, PIL, cv2, torch) happen inside functions, so every command starts fast.

External tools

Also used: SAM3 (Python, pinned commit f6e51f5, patched for macOS by patches/sam3-macos.patch), Msplat (msplat==1.1.4), SuperSplat (for view and orbit), Playwright with its Chromium (orbit), rasterio (map). Brush is pinned in scripts/install-macos.sh (1.0.0 @1388f74c), OpenMVS in scripts/install-openmvs.sh.

The monitor page

web/ is Vite + React with three.js/React Three Fiber, Spark for splats, GLTFLoader for meshes and recharts. cd web && npm run build type-checks it and writes src/gausser/web/ (gitignored), which monitor.py serves next to its JSON API. All log parsing lives in web/src/parse.ts; the CLI passes tool output through unparsed.

Install

scripts/install-macos.sh     # safe to rerun; ends with gausser status

Installs COLMAP, ffmpeg ≥ 7, Python 3.13, Node and Rust (Homebrew); splat-transform (npm); a .venv with gausser, patched SAM3 and Msplat; Brush (cargo, pinned); OpenMVS (scripts/install-openmvs.sh, about an hour the first time); SuperSplat and Playwright; the monitor page; and ~/.local/bin/gausser. Python 3.12+ is required because Msplat ships only cp312/cp313 wheels.

Development

.venv/bin/python -m pytest -q
.venv/bin/ruff check src tests
.venv/bin/mypy src
(cd web && npm run build)
.venv/bin/python scripts/build_docs.py    # this site

Tests stub external tools through require_tool/run_tool, so they never need COLMAP, Brush or SAM3. There is no CI. AGENTS.md holds the rules and hard-won constraints for anyone changing the code.

This documentation

Pages are written in docs/src/*.html; scripts/build_docs.py wraps them in the layout, inserts the generated sections (command reference, module table, import graph, tool table, scene layout, charts) and writes docs/*.html. The build fails when a command is not explained on a hand-written page, a step is missing from the pipeline chart, a module is not placed in the layers or lacks a docstring, a Scene path has no description, or a link or image is broken. Rebuild it with every change that touches commands, options, modules, steps or behaviour.
