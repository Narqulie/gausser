gausser is one command-line tool that turns photos or video into Gaussian splats. It wraps ffmpeg, SAM3, COLMAP, OpenMVS, Brush, Msplat and splat-transform behind a few steps, keeps all its state as plain files in the scene folder, and shows every run in a read-only web monitor.

Solid boxes always run in gausser run; dashed boxes are optional (--prompt, --dense, --lod, --map, --mesh). Colours are the monitor's step colours.

Start here

# guided: reads the scene, recommends the next step, prints the command it runs
gausser clip.mp4                 # makes clip/ next to the video
gausser ~/photos/statue          # a folder of photos

# direct: for scripts and overnight runs
mkdir -p statue/images && cp ~/photos/statue/*.jpg statue/images/ && cd statue
gausser run --prompt statue --monitor   # mask → solve → train, watched in the browser
gausser view                            # the result in SuperSplat

gausser alone (or gausser FOLDER, gausser VIDEO) opens the guided menu in a terminal. It never does anything the CLI cannot: it prints → gausser … and runs exactly that. gausser run is the unattended way: it skips every step that is already up to date, so rerun it after a failure or after adding photos, and use --from STEP to redo a step and everything after it. gausser status shows what the scene has, what is out of date and which tools are installed.

What to use when

you wantusewhy
a splat of an object you walked aroundgausser run --video clip.mp4 --prompt "statue"frames picks sharp frames by camera motion; the masks keep training on the subject
a whole room or streetgausser run --video clip.mp4 --denseno masks; Brush starts from the dense cloud, which removed large floaters in tests (PSNR 27.8 → 28.7 dB)
a textured meshgausser run --meshOpenMVS meshes the dense cloud; better PSNR than meshes extracted from splats
an orthophoto and height modelgausser run --mapdrone GPS georeferences the model; the splat is rendered straight down
a web-ready streamed splatgausser lodsplat-transform chunks and decimates for PlayCanvas streaming
a shareable videogausser orbitSuperSplat's own renderer circles the subject the cameras looked at
to replace a published splatgausser aligncamera presets stay valid in the published coordinates
to keep people outgausser mask person --exclude + train --exclude-maskstransient pixels are ignored, the subject masks stay

Principles

  • Files are the state. No manifest or database of its own: a step stages in .gausser/tmp/ and moves its output into place only after it succeeded.
  • Changing an input deletes what was built from it, so nothing stale is reused (Scene and state).
  • One command at a time per scene. A second one fails at once instead of overwriting the first one's work.
  • Tools are run as they are. Their output goes straight to the terminal and the step log; the monitor parses the logs.
  • Small on purpose. General tools only; use-case specific workflows stay out of the code.
